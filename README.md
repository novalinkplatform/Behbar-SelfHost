# نصب خوداستقرار بهبار

نصب کامل قالب بهبار روی یک سرور لینوکسی خودتان، با یک دستور.

## پیش‌نیاز

- یک سرور لینوکس (Ubuntu/Debian پیشنهاد می‌شود) با دسترسی root
- دو دامنه (یا زیردامنه) — یکی برای سایت مشتری، یکی برای پنل مدیریت — که رکورد A هر دو به آی‌پی همین سرور اشاره کند

## نصب

```
curl -fsSL https://raw.githubusercontent.com/siamakgarawan/Behbar-SelfHost/main/install.sh | sudo bash
```

اسکریپت دقیقاً دو سؤال می‌پرسد (آدرس دامنه‌ی سایت، آدرس دامنه‌ی پنل مدیریت)، بقیه‌ی مراحل — نصب Docker، دانلود و اجرای سرویس‌ها، صدور خودکار گواهی HTTPS، ساخت حساب مدیر — خودکار انجام می‌شود. در پایان، آدرس هر دو سایت و اطلاعات ورود پنل مدیریت (نام کاربری/رمز عبور تولیدشده) چاپ می‌شود.

## معماری

سه سرویس Docker (هرکدام یک ایمیج آماده از `ghcr.io/siamakgarawan/...`) + یک Caddy در جلو برای مسیریابی دامنه‌ها و HTTPS خودکار:

- `behbar-api` — بک‌اند (Node.js + SQLite، دیتای آن در یک Docker volume ماندگار است)
- `behbar-site` — سایت مشتری (فایل استاتیک، سرو شده با nginx)
- `behbar-admin` — پنل مدیریت (فایل استاتیک، سرو شده با nginx)
- `caddy` — دریافت ترافیک ۸۰/۴۴۳، گواهی Let's Encrypt خودکار برای هر دو دامنه، پراکسی `/api/*` به `behbar-api` و بقیه به سرویس مربوطه

ایمیج‌ها به‌صورت خودکار از سه ریپوی اصلی (`Behbar-API`، `Behbar`، `Behbar-Admin`) توسط GitHub Actions ساخته و به GHCR پوش می‌شوند — نیازی به دسترسی خریدار به سورس نیست.

## دستورات مفید بعد از نصب

همه از داخل `/opt/behbar` اجرا می‌شوند:

```
docker compose ps                 # وضعیت سرویس‌ها
docker compose logs -f behbar-api # لاگ بک‌اند
docker compose pull && docker compose up -d   # آپدیت به آخرین نسخه‌ی ایمیج‌ها
docker compose exec behbar-api cat /data/admin-credentials.txt   # دیدن دوباره‌ی اطلاعات ورود ادمین
```

## فعال‌سازی لایسنس

بعد از ورود به پنل مدیریت با حساب اولیه، به **تنظیمات سایت ← لایسنس** بروید و کد لایسنسی که هنگام خرید دریافت کرده‌اید را وارد کنید.
